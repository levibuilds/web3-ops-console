# Web3 Ops Console Visual Kit v1

Source-of-truth visual kit prepared for the existing `levibuilds/web3-ops-console` repository.

## Direction

Deep Graphite + Icy Cyan + Premium Command Center.

These are **brand/showcase assets**, not evidence screenshots. Keep the current verified product screenshots and Production Snapshot claims separate.

## Integration rules

1. Do not change snapshot numbers, source claims, security behavior, or read-only architecture to match concept art.
2. Never label concept images as actual running screenshots.
3. Preserve `34 announcements / 4 verified sources / 20 campaign records / 17 structured` until the snapshot is genuinely refreshed.
4. The public Sites build remains a static, read-only snapshot application.
5. Use the emblem-derived PNGs for favicon/app icon; use the wordmark in the header and docs.
6. Use `site-preview.webp` and `ui-kit-board.webp` as visual references when translating the style into real HTML/CSS; do not paste fake metrics from the concept directly into production.
